# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## lots

到货来源及初检。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 来源批 |
| `source` | string | 来源 |
| `age_years` | number | 服役年数 |
| `qty` | integer | 片数 |
| `purchase_cents` | integer | 整批购买额 |
| `initial_grade` | string | 初检级 |

## panels

组件分流和选择方式。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 组件 |
| `lot` | string | 来源批 |
| `grade` | string | 初检 |
| `sampling` | string | 计划随机或优先好件 |
| `prob` | number | 计划概率 |
| `suggested_route` | string | 建议 |
| `actual_route` | string | 实际路径 |
| `arrived_day` | integer | 到货日 |

显式引用：`lot` → `lots.id`。

## flows

组件费用和收入独立记录，分；没有销售记录不代表零收益。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 收支 |
| `panel` | string | 组件 |
| `kind` | string | 检测费或拆解费或再用收入或材料收入 |
| `amount_cents` | integer | 金额 |
| `day` | integer | 发生日 |

显式引用：`panel` → `panels.id`。

## route_states

处置成熟状态与等待事实。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 记录 |
| `panel` | string | 组件 |
| `state` | string | 待售或已结束或返拆中 |
| `observed_day` | integer | 观察日 |

显式引用：`panel` → `panels.id`。

## buyers

再用买家有效规格与变化。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 条件 |
| `buyer` | string | 买家 |
| `grade` | string | 可接受级 |
| `age_max` | integer | 最大年数 |
| `effective_day` | integer | 起效日 |
| `capacity` | integer | 承购片数 |

## capacities

下期检测与拆解能力。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 能力 |
| `kind` | string | 检测或拆解 |
| `day` | integer | 日序 |
| `qty` | integer | 片数 |
| `reserved` | integer | 原承诺占用 |

## quotes

已接受报价是收货义务。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 报价 |
| `lot` | string | 来源批 |
| `qty` | integer | 收货片数 |
| `price_cents` | integer | 每片价 |
| `valid_day` | integer | 有效截止 |
| `state` | string | 已接受或拟议 |

显式引用：`lot` → `lots.id`。

## reservations

已占用能力的来源。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 预留 |
| `quote` | string | 报价 |
| `capacity` | string | 能力 |
| `qty` | integer | 数量 |

显式引用：`quote` → `quotes.id`；`capacity` → `capacities.id`。
